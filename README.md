# Medical Reminder

An Android app for managing medical appointments and examinations.
Never miss an important visit again.

## About

- Separate screen for each doctor and examination
- 3 appointment types — completed, upcoming, and scheduled
  (the date by which it should take place)
- Configurable reminders — set when and how you want to be notified
- Full appointment history in one place

## Tech Stack

- Kotlin
- Jetpack Compose
- Android SDK
